# ADR-0002：座標系はGodotに合わせ、リングは円にする

## 状態

採用（2026-09-17）

## 背景

Godotの公式ドキュメントは、3Dでは1単位を1メートルとし、Yを上、X/Zを右手系とすると定めています。`Vector3.FORWARD`は(0, 0, -1)、`Vector3.RIGHT`は(1, 0, 0)です。Coreの座標をこの規約に合わせるか、独自の軸を持って変換するかを比べました。

| 軸 | Godotと同じ規約 | Core独自の規約 |
|---|---|---|
| Game側への変換 | 成分ごとの`int`から`float`への変換だけ | 軸の入れ替えが加わる |
| テストの読みやすさ | エディタ上の値と一致する | 変換表を見ながら読む |

1単位の長さは、Godotが「1単位=1m以外は推奨しない」と明記しているため、1mにします。

リングの形は、正方形、円、正八角形を比べました。円は、リングアウトの判定が中心からの距離の二乗と半径の二乗の比較だけで済み、角の無い押し出しになります。

## 決定

- Coreの座標はGodotと同じ規約です。Yが上、Xが右、Zが手前、右手系、1単位は1mです。
- 座標は`Vec3Fix`（`Fix16`のX、Y、Z）で持ちます。
- リングは原点を中心とする円です。半径はステージのデータ項目（`StageData.RingRadius`）で、コードには書きません。
- リングアウトは、キャラの足元座標について`x*x + z*z > r*r`が成り立つ時です。計算は`long`のQ32.32で行い、平方根は取りません。
- 座標成分の絶対値は1024m以下です。移動のたびに`Clamp`し、この範囲を超えません。

## 影響

- Game側はCoreの`Vec3Fix`を`Vector3`へ成分ごとに変換するだけで、軸の入れ替えをしません。
- 常に成り立つ条件C-02として「座標成分の絶対値は1024m以下」を置き、`PositionClampTests`で確かめます。
- 常に成り立つ条件C-03として「リングアウト判定は距離の二乗の比較だけで決まり、半径ちょうどはリング内」を置き、`RingOutTests`で境界値を確かめます。
