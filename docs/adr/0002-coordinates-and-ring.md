# ADR-0002：座標系はGodotに合わせ、リングの形と縁の種類はステージごとに決める

## 状態

採用

## 背景

Godotの公式ドキュメントは、3Dでは1単位を1メートルとし、Yを上、X/Zを右手系とすると定めています。`Vector3.FORWARD`は(0, 0, -1)、`Vector3.RIGHT`は(1, 0, 0)です。Coreの座標をこの規約に合わせると、画面で見た位置とCoreの値が一致し、判定の調整で見た目と数値を突き合わせられます。

リングの形と縁の種類は、リング際の駆け引きと試合の起伏を決めます。

| 軸 | 円だけ | 正方形だけ | 形をステージごとに選ぶ | 形に加え、辺ごとに壁かリングアウトかを選ぶ |
|---|---|---|---|---|
| リング際の読み合い | 縁までの距離がどの向きでも同じで、横移動で縁に沿って回れば逃げやすい | 角に追い込むと逃げ道が減り、追い込みと脱出の読み合いが強い | ステージごとに追い込みの効き方が変わる | 壁際では押し付けて攻め、リングアウトの縁では落としを狙う、と攻め方が変わる |
| 位置の分かりやすさ | 縁が曲線で、あと何歩で落ちるかが読みにくい | 縁が直線で、画面から距離を読みやすい | 形ごとに違う | 形と縁の種類ごとに違う |
| 試合の起伏 | リングアウトが起きにくく、体力勝負に寄る | 角でのリングアウトによる逆転が起きやすい | ステージ選択で試合の性格を選べる | 壁で攻めが続く場面と、落として一撃で終わる場面の両方が生まれる |
| 遊びの幅 | 1種類 | 1種類 | 3種類 | 形と縁の組み合わせで多い |

## 決定

- Coreの座標はGodotと同じ規約です。Yが上、Xが右、Zが手前、右手系、1単位は1mです。
- 座標は`Vec3Fix`（`Fix16`のX、Y、Z）で持ち、各成分の絶対値を`Limits.PositionLimitMeters`（1024m）以下に保ちます。
- リングの中心は原点です。形はステージデータの`Shape`で、`Circle`（円）、`Square`（正方形）、`Octagon`（正八角形）から選びます。大きさは`Size`で、円では半径、正方形と正八角形では中心から辺までの距離です。
- 正方形の辺iの外向きの向きは`Angle16(i * 16384)`、正八角形の辺iは`Angle16(i * 8192)`です。i=0の辺は+X側にあります。
- 縁の種類は`Edges`に持ちます。要素数は、正方形は4、正八角形は8、円は1で、各要素は`RingOut`か`Wall`です。
- 辺iの外向きの単位ベクトルn_iは`Trig.Direction`で求めます。足元の座標pについて、`(long)p.X.Raw * n_i.X.Raw + (long)p.Z.Raw * n_i.Z.Raw`が`(long)Size.Raw << 16`を超えると、その辺の外側です。円では`x*x + z*z > Size*Size`が外側です。
- `RingOut`の縁の外側へ足元が出るとリングアウトです。縁の上はリング内です。
- `Wall`の縁では、体の外周が壁を越えないよう、足元を`Size - BodyRadius`の線の内側へ押し戻します。多角形では越えた分だけ`-n_i`の向きへ戻し、円では中心からの距離が`Size - BodyRadius`になるよう中心の向きへ戻します。
- 壁への押し戻しは、移動と押し合いの後、リングアウトの判定の前に、辺の番号の順に行います。命中とガードで押し離した後と、投げの後の位置にも同じ押し戻しを行います。壁に叩きつけた時の壁やられはADR-0024で定めます。

## 影響

- ステージのデータで、リングアウトだけの舞台、壁に囲まれた舞台、一部の辺だけ壁のある舞台を作れます。
- 常に成り立つ条件C-02として「座標成分の絶対値は1024m以下」を置き、`PositionClampTests`で確かめます。
- 常に成り立つ条件C-03として「リングアウトの縁の外側へ足元が出た時だけリングアウトになり、縁の上と壁の縁ではならない」を置き、`RingOutTests`で円、正方形、正八角形の各縁の境界値を確かめます。
- 常に成り立つ条件C-34として「壁の縁では、押し戻しの後の足元が`Size - BodyRadius`の線から`Raw`で2以内の内側にある」を置き、`WallTests`で確かめます。
