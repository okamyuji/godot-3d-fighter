# ADR-0020：技の出始めに当てるとカウンターヒットになり、同時に当たれば相打ちにする

## 状態

採用

## 背景

相手が技を出している最中に攻撃を当てた時に効果が大きくなる規則があると、「うかつに手を出すと痛い」「相手の手の出し際を狙う」という駆け引きが生まれます。

同じフレームに2人の攻撃が当たった時の扱いを比べました。

| 軸 | 先に処理した側だけが当たる | 両方の命中をまとめて適用する（相打ち） |
|---|---|---|
| 公平さ | P1とP2のどちらを先に処理するかで結果が変わる | 席による差が無い |
| 見た目との一致 | 同時に当たったように見えて片方だけが倒れる | 見たとおり両者がのけぞる |

## 決定

- 攻撃が命中した時、受けた側が`Attack`の状態で経過フレームが`Startup + Active`未満（出始めか判定が出ている間）ならカウンターヒットです。
- カウンターヒットでは、ダメージが技の`CounterDamage`、硬直が`CounterHitstun`になり、`CounterKnockdown`が真ならダウンします。ガードされた攻撃はカウンターヒットになりません。
- 命中とガードは、2人分の当たり判定をすべて同じフレームの状態から先に求め、その後でまとめて適用します。相打ちでは、各自が相手の技の効果を受けます。同じフレームに2人とも判定が出ていれば、2人ともカウンターヒットです。
- 命中（ダウン中への命中を含む）またはガードが起きたフレームは、関わった2人の`HitstopFrames`を、現在の値と技の`Hitstop`の大きい方にします。相打ちでは2つの技の`Hitstop`の大きい方を2人に使います。
- 各プレイヤーの`LastHitKind`に、そのフレームに受けた結果（命中、カウンターヒット、ガード、投げ、投げ抜け）を記録します。Game側はこの値で「COUNTER」などの表示と効果音を出します。

## 影響

- カウンターヒットでだけつながる連続技や、ダウンを奪える技をデータで作れます。
- 常に成り立つ条件C-27として「出始めと判定が出ている間に受けた命中だけがカウンターヒットになり、ガードはカウンターヒットにならない」を置き、`CounterHitTests`で確かめます。
- 常に成り立つ条件C-28として「2人の攻撃が同じフレームに当たると、処理の順に関係なく2人とも相手の技の効果を受ける」を置き、`TradeTests`でP1とP2を入れ替えた2通りを比べて確かめます。
