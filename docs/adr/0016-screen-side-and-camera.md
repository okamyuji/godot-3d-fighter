# ADR-0016：画面上の左右はカメラの向きから決め、位置が入れ替わっても視点を回さない

## 状態

採用

## 背景

レバーの前後は、プレイヤーが画面の左に立つか右に立つかで決まります。投げで相手の後ろへ回った時や、横移動で回り込んだ時に、2人の位置は入れ替わります。

| 軸 | 席で前後を固定し、入れ替わるとカメラを半周回す | カメラの向きを試合状態に持ち、入れ替わると画面上の左右を入れ替える |
|---|---|---|
| 画面の見やすさ | 入れ替わりの瞬間に視点が半周し、プレイヤーが状況を見失う | 視点は動かず、キャラの立ち位置だけが入れ替わる |
| 操作の分かりやすさ | 画面の右へ歩くつもりで左へ歩くことがある | 画面上の見た目どおりに前後が決まる |
| 裏に回る攻めの価値 | 視点が回るので、裏を取った状況が伝わりにくい | 裏を取ったことが画面で分かり、攻めとして成立する |
| ロールバックとリプレイ | カメラが状態の外にある | カメラの向きも復元される |

## 決定

- `MatchState`に`CameraYaw`（`Angle16`）を持ちます。値は画面の右方向の角度で、0は+Xです。ラウンド開始時は0で、P1が−X側（画面の左）、P2が+X側（画面の右）に立ちます。
- 毎フレーム、向きの更新の後で、P1からP2への角度αを`Atan2`で求めます。候補はαとα+32768です。候補から`CameraYaw`を引いた値を`unchecked`で`short`に変換し、その絶対値（`int`で計算）が小さい方を新しい`CameraYaw`にします。等しい時はαを選びます。2人の水平距離が0の時は更新しません。
- 新しい`CameraYaw`がαならP1が画面の左、α+32768ならP2が画面の左です。
- 画面の左に立つプレイヤーは、レバーの右が前、左が後ろです。画面の右に立つプレイヤーは、左が前、右が後ろです。レバーの上は常に画面の奥、下は常に画面の手前です。
- 横移動の向きは、画面の左に立つプレイヤーでは奥が`Facing + 16384`、手前が`Facing - 16384`です。右に立つプレイヤーでは奥が`Facing - 16384`、手前が`Facing + 16384`です。
- Game側のカメラは、2人の足元の中点から`CameraYaw - 16384`の方向（画面の手前）へ離れた位置に置き、中点の1m上（2人の腰から胸の高さ）を見ます。見た目のなめらかな追従はGame側で行い、`CameraYaw`は書き換えません。

## 影響

- 不変条件C-20として「ラウンドの開始と位置のリセットで0に戻すフレームを除き、`CameraYaw`は1フレームで16384を超えて変わらない。画面の左に立つプレイヤーは、前のフレームの左右を保つ候補と`CameraYaw`の差の絶対値が16384を超えたフレームと、ちょうど16384でその候補がα+32768のフレームにだけ入れ替わる」を置きます。`CameraSideTests`で、投げの終わりで裏へ回した時に入れ替わること、横移動で回り込み続けても入れ替わらないことを確かめます。
