# ADR-0017：ボタンは押した瞬間に受け付け、先行入力と同時押しの猶予を持たせる

## 状態

採用

## 背景

コマンドの受け付け方は、狙った技が出るか、狙っていない技が出ないかを決め、操作の手触りに直結します。

| 軸 | 押した瞬間だけ受け付ける | 押している間も受け付ける |
|---|---|---|
| 暴発 | ボタンを押したままでも技は1回だけ出る | 硬直が切れるたびに同じ技が出てしまう |
| 連続技の入力 | 押し直した回数だけ技が出るので、狙いどおりに刻める | 意図しない技が混ざる |

| 軸 | 先行入力なし | 硬直が切れる直前の入力を受け付ける |
|---|---|---|
| 反撃の決めやすさ | 硬直が切れた1フレームちょうどに押す必要がある | 少し早めに押しても最速で出る |
| 上級者と初心者の差 | 入力の正確さだけで差が付く | 読みと判断で差が付く |

| 軸 | 技番号の大きい方を選ぶ | 入力の要素が多い方を選ぶ |
|---|---|---|
| 「P」と「6P」が同時に成立 | データの並び次第で6Pが出ない | 6Pが出る |
| 「P」と投げ「P+G」が同時に成立 | データの並び次第で投げが出ない | 投げが出る |

## 決定

- 方向の数字はテンキーの配置で、画面上の立ち位置から決まる前後（ADR-0016）を基準にします。1が下後ろ、2が下、3が下前、4が後ろ、5がレバー中立、6が前、7が上後ろ、8が上、9が上前です。
- 技のコマンドは、方向の数字0〜4個に続けて、ボタン1〜3個を`+`でつないだ文字列です。形は`^[1-6]{0,4}[PKG](\+[PKG]){0,2}$`で、ダッシュの「66」「44」は、ボタンを持たない組み込みのコマンドで、技データには書きません。方向に7、8、9を含むコマンドは認めません。上は横移動の入力に使うためです。形に合わない技データは読み込み時に例外です。
- ボタンは押した瞬間（そのフレームで押され、1フレーム前に押されていない）を受け付けます。
- 複数ボタンの技は、Gを除く各ボタンが直近`Limits.SimultaneousPressFrames`フレーム以内に押され、判定するフレームで全ボタンが押されている時に成立します。Gは押し続けていても構いません。ガードを固めたままPを押すと投げ「P+G」が成立します。
- 方向が1個の技（例「6P」）は、ボタンが成立したフレームのレバーの方向が一致すれば成立します。
- 方向が2個以上の技（例「236P」「66」）は、各方向を「そのフレームで新しく入った方向」として、最後の方向から過去へ順に探します。最後の方向はボタンのフレーム（ボタンの無いコマンドでは判定するフレーム）から`Limits.CommandWindowFrames`フレーム以内、それより前の方向は1つ後の方向が見つかったフレームから`CommandWindowFrames`フレーム以内に現れる必要があります。
- 方向の一致は完全一致です。「3」に「6」や「2」は含みません。
- 方向が0個の技（例「P」）は、レバーの向きを問いません。
- 行動できない状態から行動できる状態へ戻ったフレームでは、ボタンが直近`Limits.BufferFrames`フレーム以内に成立していれば技を出します（先行入力）。横移動とダッシュの取り消し可能時点に入ったフレームも同じです。
- 同じフレームに複数の技が成立した時は、方向の要素が多い技、次にボタンの数が多い技、次に技番号の小さい技を選びます。
- 行動できるプレイヤーは、毎フレーム次の順で行動を決めます。技と投げ、ダッシュ、横移動、ガード（Gを押していれば、下方向ならしゃがみガード、それ以外は立ちガード）、しゃがみ（1、2、3）、歩き（6は前歩き、4は後ろ歩き）、立ち（5、7、8、9）の順です。

## 影響

- 最も長いコマンドでも、方向4個に猶予10フレームずつと先行入力5フレームで45フレーム以内に収まり、64フレームの入力履歴（ADR-0003）で判定できます。
- 常に成り立つ条件C-21として「ボタンを押し続けても技は1回だけ成立し、同時押しは`SimultaneousPressFrames`以内の差で成立し、それを超えると成立しない」を置き、`CommandParserTests`で確かめます。
- 常に成り立つ条件C-22として「複数の技が成立した時は、方向の要素、ボタンの数、技番号の順で1つに決まる」を置き、`CommandPriorityTests`で確かめます。
- 常に成り立つ条件C-23として「硬直が切れる`BufferFrames`フレーム前までのボタン入力で、硬直が切れたフレームに技が出る」を置き、`InputBufferingTests`で確かめます。
