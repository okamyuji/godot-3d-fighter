# ADR-0014：向きは16bitの角度で持ち、sin/cosの表で回転する

## 状態

採用

## 背景

キャラは常に相手の方を向き、技の判定位置や横移動の方向は向きを基準に決まります。向きを角度で持つ方式と、相手への単位方向ベクトルで持つ方式を比べました。

| 軸 | 16bit角度とsin/cosの表 | 単位方向ベクトル |
|---|---|---|
| 必要な数学 | sin/cosの表と整数のatan2 | 整数平方根 |
| 精度 | 角度の刻みで決まる | 各成分がQ16.16精度 |
| 相手を向かない技への拡張 | 角度が自然 | 回転の表が後から要る |

`Math.Sin`と`Math.Atan2`はCoreで使えません（ADR-0001、ADR-0009）。表は事前に生成してC#ソースとしてコミットします。生成ツールはCoreの外にあり、実行時には使いません。

## 決定

- 向きは`Angle16`（`ushort`）で、1周を65536とします。0は+X方向で、値が増えると−Z方向へ回ります。角度θの向きベクトルは`(cos θ, 0, -sin θ)`です。
- sinの表は1024要素の`int`配列（Q16.16）で、`src/Core/Math/SinTable.g.cs`にコミットします。添字は`angle >> 6`で、補間はしません。cosは`Sin(angle + 16384)`です。
- 表の生成は`tools/GenTables`（コンソールアプリ）が行います。生成には`double`を使ってよく、各要素は最近接のQ16.16へ丸めます。生成結果はコミットし、CIで再生成して差分が無いことを確かめます。
- 整数のatan2は、8分円へ還元してから、比`min/max`（Q16.16、0から1）の`Raw >> 8`を添字にしてatan表を引き、還元を戻します。比が1のとき添字は256になるため、表は257要素（添字0から256）です。戻り値は`Angle16`で、`Atan2(0, 0)`は0を返します。
- 相手への向きは毎フレーム`Atan2(-dz, dx)`で求めます（dx、dzは相手の足元座標との差）。
- 入力の上下と横移動の対応、カメラの向きはADR-0016で定めます。

## 影響

- 角度の刻みは360÷1024で約0.35度です。判定位置の回転誤差は半径1mで約6mmで、判定の半径より十分小さい値です。
- 制約条件C-15として「`Sin(0)=0`、`Sin(16384)=One`、`Sin(32768)=0`、`Sin(49152)=-One`で、表の各角度で`sin^2 + cos^2`が`One`から3以内」を置き、`TrigTableTests`で確かめます。
- 制約条件C-16として「`Atan2(0, 1)=0`、`Atan2(1, 0)=16384`、`Atan2(1, 1)=8192`、`Atan2(0, -1)=32768`、`Atan2(-1, 0)=49152`」を置き、`Atan2Tests`で確かめます。
